# ميزانيتي — مشروع APK

## الخطوات
1. أنشئ مستودعاً جديداً على GitHub (اسمه مثلاً my-budget).
2. ارفع كل محتويات هذا المجلد إليه (بما فيها المجلد المخفي .github).
3. افتح تبويب Actions في المستودع، واختر Build APK ثم Run workflow
   (أو سيعمل تلقائياً عند أول رفع على الفرع main).
4. بعد نحو 5 دقائق افتح التشغيل المكتمل، ونزّل my-budget-apk من قسم Artifacts.
5. فك الضغط، وانقل app-debug.apk إلى الهاتف وثبّته (فعّل التثبيت من مصادر غير معروفة).

## تعديل التطبيق
عدّل الملف www/index.html ثم ارفعه، وسيُبنى APK جديد تلقائياً.
